## 发布准备

- GitHub Pages 使用 main 分支的 Actions 流程，Linux / Windows 和 Node 20 / 22 / 24 检查完成后发布前端。
- 后端使用 `/opt/sameko-weibo-lottery/source` 的干净 Git 提交运行安装脚本。独立构建目录、安装 Chromium、浏览器稳定性检查完成后再切换 current。
- 安装器保留环境文件与 output 数据。新服务启动健康检查同时覆盖后台入口和所有静态模块，失败时自动恢复上一版本与 systemd 配置。
- 发布前核对现有应用的队列与磁盘容量，记录旧发布提交及必要的回滚信息；备份只保存在服务器上的受限目录，不上传 GitHub。
- 发布后核验 GitHub Actions、Pages 产物、后端版本、真实后台摘要、匿名访问边界、CORS、默认延迟与服务日志。
