# 3.6.2 最终复核

本轮按运营者要求沿用 3.6.2，仅将其发布日期改为 2026-11-06。公开日志的标题、内容与 3.6.1 历史条目保持不变。本文记录工程验证，不增加产品更新日志。

## 修复

- 备份读取或等待存储锁期间清空本机记录，旧导入不再恢复已清空的数据。开始新的开奖或演练后，旧导入不会清掉新结果；读取期间禁用重复导入并显示状态。
- 后台删除开奖记录或反馈后立即移除对应列表项和详情缓存，并发起新的刷新。旧刷新及其结束回调不能覆盖新刷新状态，退出后的迟到删除响应也不能更改新会话。
- 后台扫码的开始、停止与 Cookie 刷新使之前的总览和状态请求失效，避免刚显示的二维码消失或停止后被旧状态重新开启。

复核范围包括来源载入与补抓契约、重复中奖及保存幂等、本机历史与导入、后台列表和扫码、接口鉴权、持久化及部署边界。页面回归覆盖四个主页面、来源和奖项设置、确认和结果弹窗、设置和法律说明、反馈、后台总览、记录、诊断和 Cookie 页面。

- `npm run test:release` 退出 0：306 项单元测试、61 项抓取服务测试、24 个页面回归脚本通过。
- HTTP、Cookie 只读接口、记录恢复、部署契约、进程和浏览器生命周期及内存检查通过；依赖审计 0 个已报告漏洞，构建、许可证、法律字段与版本检查通过。
- 新备份导入回归先在原实现复现失败，再验证慢读取、等待锁、正常合并、无效文件和新演练。后台回归以合成接口延迟响应，旧代码分别在删除刷新与二维码保持断言失败，修复后通过。
- WebKit 的手机视口、键盘避让及本次备份导入、后台删除与扫码竞态检查通过。Windows WebKit 中计划 2.6 秒的轮询实测约 5.9 秒后执行，附加测试将等待上限调整为 20 秒后通过，未改变生产请求间隔；这不是 iPhone 真机验证。
- 本地测试使用隔离运行目录及合成数据；不以批量真实抓取、真实扫码或写入正式开奖记录作为回归验收。
