运营者本轮确认：个人公益、免费运营，本人与服务器均在美国怀俄明州，仅向美国与中国大陆的朋友分享测试，不开展公众推广、收费参与或带货。以这一最新澄清为准，不沿用早前“公开网站”的用途描述。“公益”描述免费性质，不表示已取得慈善机构或免税资格。

本轮核查了工作区代码、默认部署模板与官方公开资料。未读取 Cookie、密钥、登录 Profile、真实开奖记录或生产访问日志，未核实线上防火墙、当前环境变量、托管合同、备份、真实身份及素材授权凭证；未修改生产配置、删除数据或部署。运营者与机房位置依据用户确认，不是独立地理审计结果。

[《中华人民共和国个人信息保护法》——国家网信办](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)：第 3 条规定境外处理境内自然人信息的适用条件；第 72 条排除自然人因个人或家庭事务进行的处理。朋友内测是否属于该例外，需要结合实际活动判断，不能仅凭名称确定。第 13、17、27 条涉及处理依据、告知和公开信息合理范围；第 28、31 条涉及敏感信息及不满十四周岁未成年人。第 38、39、55 条涉及适用时的跨境安排与影响评估；若属于第 3 条第二款的境外处理者，还须核实第 53 条境内机构或代表要求。第 44—50 条涉及个人权利，第 57 条涉及安全事件处置。
2. [《促进和规范数据跨境流动规定》——国家网信办](https://www.cac.gov.cn/2024-03/22/c_1712776611775634.htm)：2024-03-22 公布施行。第 5 条等对符合条件的数据出境规定部分程序豁免；第 10 条仍要求依法履行告知、单独同意、影响评估等义务。程序豁免不等于没有隐私义务，且不能只按网站测试账号数量判断适用门槛。
3. [17 U.S.C. § 107——美国政府出版局，2024 Edition](https://www.govinfo.gov/content/pkg/USCODE-2024-title17/html/USCODE-2024-title17-chap1-sec107.htm)：合理使用需综合使用目的、作品性质、使用数量与实质性、市场影响等因素；非商业性质只是相关因素之一，不是自动授权。该版本用于核对条文原则，并非对具体图片的法律结论。

[What is GitHub Pages?——GitHub 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)：Data collection 一节明确访问者 IP 会为安全目的被记录和保存，与是否登录 GitHub 无关；同时参照 [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。
