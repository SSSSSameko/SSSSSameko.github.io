# 界面设计约定

此文件描述 3.6.2 的当前设计。用户已明确撤回旧的单色与灰玫瑰方向；此前的风格结论不再作为设计约束。产品事实见 PRODUCT.md，当前设计方向见 DESIGN.md。

## 白色界面与功能色

| 用途 | 浅色前景 | 浅色底色 |
| --- | --- | --- |
| 正文 | #273345 | #ffffff |
| 辅助文字与输入 | #667386 | #f8f9fc |
| 来源与链接 | #2868c7 | #edf4ff |
| 奖项 | #b6573d | #fff0e9 |
| 规则与连接 | #23816d | #ebf7f2 |
| 名单与偏好 | #7956b8 | #f3effc |
| 主操作 | #34435a | #ffffff |

彩色用于图标、浅色图标容器、候选卡片的背面叠层和导航选中态；主按钮保持白底深字。
正文与辅助文字保持可读对比，图标在浅色容器上的对比度均超过 3:1。辅助文字对输入底色为 4.57:1。
成功、警告和错误保持原有语义，同时提供文字，不依靠颜色单独传递状态。

## 层次与布局

顶部采用轻量工具栏，教程与设置分别有淡蓝和淡紫的圆形触控范围。候选卡片以淡蓝、淡橙叠层表达候选集合；
待载入状态显示载入、确认、抽取的准备顺序，不显示虚构人数。主要操作以细边缘与短软投影突出，
内容分组使用细线与留白，背景不铺设装饰光晕。

列表功能图标采用统一的圆角方形容器。设置入口与弹层标题使用相同的功能色。底部导航保持单个白色选中块，
按所在页面切换符号与文字颜色；鼠标悬停不覆盖已经选中的颜色。

桌面把抽奖设置置于操作区右侧。手机保持紧凑首屏，短屏减少卡片辅助信息，横屏并排展示卡片与输入操作。
深色模式单独配置图标颜色与容器，主按钮仍然是白底深字。

表单本身不再套一层白框或背景模糊，输入区域保留细边界；搜索输入移除叠加的灰色底。
内容容器使用短接触阴影与低透明度扩散阴影，结果摘要稍突出；确认信息、奖项统计和随机过程记录用分隔线组织，减少嵌套卡片。
弹层底部保留很轻的上缘投影，让固定操作与可滚动内容的关系清楚。

## 交互与可访问性

保留 44px 触控范围、16px 手机输入字号、键盘导航与清楚的焦点。页面切换保留滚动，
快速点击取消旧动画，减少动效遵循现有用户设置。颜色调整不改开奖规则、错误恢复或保存逻辑。

Safari 保留 VisualViewport 键盘避让、安全区域和双指缩放；iPhone 通过分享菜单添加到主屏幕，
从桌面图标使用独立窗口。普通标签页无法由网站强制隐藏地址栏，安装指引保留本机记录导出的提示。

名单页和来源弹层均提供下一步操作，统一调用已有开奖检查后进入奖项设置、规则调整或开奖前确认。
来源编辑后必须重新载入，载入中不能继续。名单页可主动收起来源表单，收起不清空输入；来源变动或刷新时重新显示编辑区。
完成后显示带文字的「再次抽奖」「查看结果」。结果弹层的保存图片、复制文案置于第一排，分享文案、复制名单和导出名单置于第二排，减少手机上的固定操作区高度。

## 验证与参考

3.6.2 在现有白色与功能色基础上收紧细节：舞台底色为 `#fbfcfe`，减轻卡片投影；列表说明允许两行，避免手机上重要信息被单行截断。
按钮按压采用 120ms 反馈并保持 88% 不透明度；弹层进场 280ms，背景模糊降为 5px，导航首次入场为 260ms，无额外等待。
键盘与减少动效保留独立行为。具体审查、前后截图和验证见 [本地复审记录](LOCAL-REVIEW-3.6.2-2026-11-05.md)。以下为初版设计过程的验证记录。

本轮使用 frontend-design 与 Impeccable 的工作界面设计方法，并以当前产品功能和用户最新要求确定方向。
未把旧风格记录作为约束。当前截图与验证日志保存在 output/redesign-color-20261105/；
修改前的界面文件仅作本机回退备份，保存在该目录的 before/ 中。
