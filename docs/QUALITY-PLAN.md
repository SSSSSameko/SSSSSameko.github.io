# 整体质量审查与优化

目标：对标成熟的桌面和手机网页，完成前后端代码、功能、实用性、可用性、操作流程和动效的整体优化。
本文记录 3.6.0（两天的开发版本合并）的质量计划与历史验收；未发布。当前版本以 `package.json` 为准，最后一次上线前审查见 [PRELAUNCH-REVIEW-2026-11-05.md](PRELAUNCH-REVIEW-2026-11-05.md)。

## 验收范围

| 范围 | 验收要求 | 当前证据 |
| --- | --- | --- |
| 主流程与数据正确性 | 载入、筛选、奖项、演练、正式保存、重试、导出与恢复；交叉操作不串数据 | 提炼 useDrawCount，先复现 9 被旧查询改为 2，再通过跨链接、后端、密钥、载入和保存回归；既有主流程纳入当前整套验收 |
| 服务可靠性 | 队列、取消、共享任务、限流、上游异常、持久化恢复、生命周期和资源上限 | 复核编排与模块；修复静态编码协商；HTTP、恢复、生命周期和 38 项微博服务回归通过；共享取消保留其他订阅 |
| 界面与可用性 | 手机、平板、桌面、短屏、横屏；关键操作可达且状态明确 | 亮白按钮与彩色点缀已落实；3.9.5 手机/桌面截图及当前多尺寸界面检查 |
| 交互与动效 | 连续点击、键盘导航、弹层返回、滚动恢复、减少动效及忙碌/错误/空态 | tablist、sheet-motion、draw-animation、error-recovery 等回归进入当前整套验收 |
| 性能与可维护性 | 首屏网络和渲染、大名单操作、动画、服务内存/进程；职责收口 | 两万候选搜索与筛选通过；记录 4 倍 CPU 降速样本；有界服务压力与浏览器回收检查通过；提炼次数查询职责 |
| 安全与兼容 | 鉴权、输入输出边界、凭据生命周期、SSRF、依赖审计；Chromium 与 WebKit | 283 项单测与 0 漏洞依赖审计；WebKit 手机检查通过；未放宽生产 CSP、SSRF 或凭据边界 |
| 最终综合验收 | 当前版本完整 test:release、WebKit 和视觉检查，问题清单无未说明缺口 | 最终 test:release 退出码 0，283 项单测、38 项微博服务测试及 20 组 UI 通过；WebKit 手机检查通过；测试夹具跨端口问题已修正并重跑 |

所有测试使用隔离数据。不更改线上记录、凭据或固定法律文案。本目标不包含未经用户明确要求的部署。
