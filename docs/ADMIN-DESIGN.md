# 后台查看与诊断设计 · 3.6.1

对齐目前前端的亮白控件、石墨文字、彩色功能图标和轻层次。保留总览、记录、反馈、Cookie、系统五个入口，以及现有权限、导出与删除确认流程。

## 视觉与交互

- 背景 `#fafbfd`，内容 `#ffffff`，主文字 `#17181d`，次文字 `#616570`。色彩用于图标、状态和聚焦提示；主按钮保持亮白。
- 蓝色 `#0062c4` 表示链接和定位，绿色表示连接状态，橙红色提示需要检查的问题。每种状态同时提供文字，避免只靠颜色判断。
- 主文字与白底对比度 17.72:1；次文字 5.83:1；辅助文字 `#6b717d` 与浅层背景 `#f6f8fb` 为 4.61:1。
- 深色模式跟随系统；主文字与内容底色为 15.63:1，次文字与输入背景为 7.03:1。亮白主按钮文字对比度 13.74:1。
- 桌面顶部胶囊导航；手机底部五项导航，避开安全区域，输入字号至少 16px，操作目标至少 44px。软件键盘压缩可视区时隐藏底栏；缩放不当作键盘。
- 保留键盘焦点、方向键切换、手机详情焦点约束；减少动效、减少透明度与强制色彩模式继续生效。

## 信息组织

总览先显示资源指标和需要检查的入口。后台连接成功只表示管理连接正常，不代表微博或所有服务正常。近期异常明确属于保留日志窗口，不断言故障仍然持续。

系统页分为事件排查、抓取过程、服务资源、安全与 HTTP。事件支持关键词、级别、分类、时间筛选和逐批显示。保留原有资源、请求、存储、安全诊断。运行指标每分钟刷新，可暂停；底层内存采样周期仍为五分钟。

抓取仅按明确的 `crawlId` 关联，显示声明总数、实际条数、缺口、容差、耗时和各渠道真实新增/重复数。没有最终事件显示“缺少最终结果”，不能推断为仍在运行。数量达到接口声明值不等于平台全部转发可见；容差停止显示部分名单。旧记录缺字段显示未知或未记录。

系统摘要最多提供最近 300 条事件。相同抓取编号、动作、终止时刻和完整载荷的结果镜像可去重；无关联编号的重复错误继续保留。筛选结果与任务列表均说明窗口限制。

记录详情补充来源证据，关联跳转严格匹配抓取编号。刷新保留诊断筛选与展开状态；退出清空新增页面的数据与筛选。

复制诊断摘要使用字段白名单，仅包含版本、级别计数、抓取编号和数量结果，不复制原始错误文本、请求头、响应体、地址或凭据。后台内的技术详情仍受现有身份认证保护。

## 本地预览与验证

`node scripts/preview-admin.mjs` 在 `http://127.0.0.1:5197/admin/` 提供明确标注的模拟预览。只监听本机，所有数据均为合成夹具，写入操作返回 405，不调用微博和真实后台。与生产服务独立。

纯模型验证见 `src/lib/adminDiagnostics.test.js`。后台界面回归见 `scripts/test-admin-ui.mjs` 和 `scripts/test-admin-diagnostics-ui.mjs`；后者可用 `ADMIN_UI_ENGINE=webkit` 额外检查 WebKit。发布回归包含两个后台脚本。截图写入忽略目录 `output/ui-checks/`。

采用 Apple HIG 的层次、渐进披露、语义色彩、动态深色与可访问性原则，并保持网页现有操作习惯。WebKit 自动化不能替代真实 iPhone 键盘和系统浏览器的最终体验确认。
